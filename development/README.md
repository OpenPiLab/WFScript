# Regression fixtures (not part of the application)

These files are historical source fixtures retained **only** because the Python/Node regression tests
in `tests/` compare behavior across earlier Panels, driver workflows, and data volume cases.
They are not installed by the application or presented as current examples.

For user-facing examples open **`examples/panels/`** from WFScript or browse **`docs/site/examples.html`**.
The larger development-history collection remains in the original RC1.5.14.10.8 source archive,
not in this cleaned v0.2 release.

Do not remove these fixtures casually: first update and run all dependent offline tests.
