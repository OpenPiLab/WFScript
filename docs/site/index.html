From an idea to a working interface

WFScript keeps an application together as a portable .wfpanel project. Use an existing example or start on a blank Page. Add controls and displays, write small named handlers, connect real instruments when needed, and keep measurement results and reports with the work.

Real examples you can open and change

The DSP Studio creates a simulated signal and plots its waveform, FFT and response. The Panel Data Lab demonstrates one shared value driving several widgets. The Automated Test Station demonstrates native results and reports.
